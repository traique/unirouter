Providers

Nguồn model AI. Mỗi provider có thể có nhiều key để xoay vòng; model auto dùng tất cả provider đang hoạt động.

Combo / Alias

Tên model ảo trỏ tới nhiều model thật. Không bắt buộc: model auto đã tự định tuyến.

API Keys

Mỗi bot hoặc ứng dụng một key. Key chỉ hiện đầy đủ một lần lúc tạo.
